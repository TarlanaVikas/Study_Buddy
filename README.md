## ✨ About

**Study Buddy** is a modern browser-based study productivity application that combines **task management, scheduling, focused study sessions, progress tracking, and achievements** into one platform.

It is built with pure **HTML, CSS, and JavaScript**, with browser **LocalStorage** used for persistent data.

---

## 🚀 Features

### 📋 Task Management

* Create, edit, delete, and complete tasks
* Set subject, priority, description, due date, and estimated time
* Search and filter tasks
* Track pending and completed work

### 📅 Study Calendar

* Monthly calendar navigation
* Current-day highlighting
* Task/deadline indicators
* Date-based task viewing

### ⏱️ Pomodoro Timer

* Focus, short-break, and long-break sessions
* Start, pause, and reset controls
* Customizable timer durations
* Automatic focus/break transitions
* Focus session tracking
* Completion notifications

### 📊 Progress & Statistics

* Task completion statistics
* Study-time tracking
* Weekly progress
* Subject-wise progress
* Study streak tracking

### 🏆 Achievements

* First Task
* 7-Day Streak
* 25 Hours
* Perfectionist

### 🔔 Notifications

* Task updates
* Timer events
* Study reminders
* Achievement notifications

### 🌙 Themes & Responsive UI

* Light and dark mode
* Responsive desktop/tablet/mobile layouts
* Mobile navigation
* Kinetic editorial-inspired UI
* Floating animations and interactive transitions

## ⚙️ Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/study-buddy.git
cd study-buddy
```

### Run locally

Simply open:

```text
index.html
```

in your browser.

For development, **VS Code + Live Server** is recommended.

---

## 💾 Data Storage

Study Buddy currently uses browser **LocalStorage**, so no backend or database setup is required.

Stored information includes:

* Tasks
* Goals
* Settings
* Statistics
* Study progress

> Data is stored locally on the current browser/device and is not synchronized across devices.

---

## 🌐 Deployment

Study Buddy is a static web application and can be deployed easily using:

* **Vercel**
* **GitHub Pages**
* **Netlify**
* **Cloudflare Pages**

No backend server is required.
